## Ìtọ́kasí Kíákíá

**Ṣé o ṣẹ̀ṣẹ̀ bẹ̀rẹ̀ sí í lo OmniRoute?** Bẹ̀rẹ̀ níbí — àwọn wọ̀nyí ń yanjú 90% àwọn ìṣòro:

| Ohun tí mo rí              | Ohun tí ó túmọ̀ sí                          | Ohun tí o yẹ kí o ṣe                                                                                               |
| -------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| "Kò lè sopọ̀"               | OmniRoute kò ṣiṣẹ́                          | Ṣiṣe `omniroute` tàbí `docker restart omniroute`                                                                   |
| "Kọ́kọ́rọ́ API kò tọ́"         | Kọ́kọ́rọ́ rẹ kò tọ́ tàbí ó ti parí             | Ṣàdàkọ kọ́kọ́rọ́ náà lẹ́ẹ̀kan sí i láti ojú-òpó wẹ́ẹ̀bù olùpèsè náà                                                       |
| "A ti kọjá òpin ìwọ̀n"      | O ń fi àwọn ìbéèrè púpọ̀ jù ránṣẹ́           | Dúró fún ìṣẹ́jú 1, tàbí lo `model: "auto"` fún ìyípadàpadà aládàáṣiṣẹ́                                               |
| "A ti kọjá iye ààyè lílò"  | O ti lo gbogbo iye ààyè ọ̀fẹ́/tí o sanwó fún | So àwọn olùpèsè míì pọ̀, tàbí lo àwọn olùpèsè ọ̀fẹ́ (Kiro, Pollinations)                                              |
| "Àwọn ìdáhùn lọ́ra"         | Olùpèsè dí lọ́wọ́ tàbí ó jìnnà               | Lo `model: "auto/fast"` tàbí so olùpèsè tó yára sí i pọ̀ (Groq, Cerebras)                                           |
| "Olùpèsè tí kò tọ́ ni a lò" | `auto` yan olùpèsè mìíràn                  | Ìyẹn jẹ́ ohun tó yẹ! `auto` máa ń yan èyí tó dára jù. Fi tipátipá lo olùpèsè kan pàtó pẹ̀lú `model: "openai/gpt-4o"` |
| "502 Ẹnu-ọ̀nà Búburú"       | Olùpèsè kò ṣiṣẹ́                            | Dúró kí o sì tún gbìyànjú, tàbí lo `model: "auto"` láti yí olùpèsè padà                                            |
| "401 Kò Ní Àṣẹ"            | Àwọn ẹ̀rí ìdánimọ̀ rẹ kò tọ́                  | Ṣàyẹ̀wò kọ́kọ́rọ́ API rẹ tàbí tún ṣe ìfàṣẹsí pẹ̀lú OAuth                                                                |
| "429 Àwọn Ìbéèrè Púpọ̀ Jù"  | A ti dín ìwọ̀n ìbéèrè kù                    | Dúró fún ìṣẹ́jú 1, tàbí so àwọn olùpèsè míì pọ̀                                                                      |

**Ṣé o ṣì di mọ́lẹ̀?** Wo [ìtọ́jú ìṣòro ní ẹ̀kúnrẹ́rẹ́](#detailed-troubleshooting) ní ìsàlẹ̀, tàbí béèrè lórí [Discord](https://discord.gg/U47eFqAXCn).

## Ìtọ́jú Ìṣòro Ní Ẹ̀kúnrẹ́rẹ́

---

### Dídín Ìwọ̀n Ìbéèrè Kù Lórí Àwọn Olùpèsè Ọ̀fẹ́ (429 / 400 / 401)

**Àmì ìṣòro**: Nígbà tí o bá ń lo `model: "auto"` pẹ̀lú àwọn olùpèsè ọ̀fẹ́/tí kò nílò ìfàṣẹsí (opencode, auggie, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ), lẹ́ẹ̀kọ̀ọ̀kan o máa ń gba `HTTP 429`, `400`, tàbí `401` dípò àwọn ìdáhùn. Àwọn ìbéèrè náà máa ń ṣàṣeyọrí nígbà tí o bá tún ìbéèrè kan náà gbìyànjú ní ìṣẹ́jú díẹ̀ lẹ́yìn náà, ṣùgbọ́n ìmúṣiṣẹ́-aládàáṣiṣẹ́ (àwọn iṣẹ́ cron, àwọn aṣojú, àwọn script) máa ń dáwọ́ dúró ní ìkùnà àkọ́kọ́.

**Okùnfà ìṣòro**: Àwọn ọ̀nà ìkùnà mẹ́ta tí kò gbára lé ara wọn ń kóra jọ:

1. **Ìdínwọ́ ìwọ̀n olùpèsè (`429`)**: Àwọn ìpele ọ̀fẹ́ lè fi iye ààyè lílò fún àkókò kọ̀ọ̀kan múlẹ̀. Ọ̀pọ̀ ìpè tó wá lẹ́ẹ̀kan náà máa ń parí rẹ̀, nítorí náà a ó kọ ìbéèrè tó tẹ̀ lé e títí àkókò náà yóò fi tún bẹ̀rẹ̀.
2. **Model tó bàjẹ́ nínú passthrough (`400`/`401`)**: Àwọn àkójọpọ̀ `auto/*` lè ní àwọn model passthrough láti `opencode` tí a forúkọ sílẹ̀ nínú àkójọ ṣùgbọ́n tí kò ní ẹ̀rí ìdánimọ̀ tó ń ṣiṣẹ́ (fún àpẹẹrẹ `oc/north-mini-code-free` → `401`). Auto-router máa ń gbìyànjú ọ̀kan, ó kùnà, a sì máa tan àṣìṣe náà ká kí fallback tó bẹ̀rẹ̀.
3. **Ìmúgbòòrò ìṣiṣẹ́pọ̀ lẹ́ẹ̀kan náà (`429` lábẹ́ ẹrù)**: Nígbà tí ọ̀pọ̀ àwọn ìpàdé aṣojú/cron bá kọlu `auto` lẹ́ẹ̀kan náà, àpapọ̀ ìwọ̀n ìbéèrè máa ń kọjá ohun tí àwọn olùpèsè ọ̀fẹ́ lè gbà, nítorí náà a máa ń sàmì sí àwọn ìpè tó bófin mu gẹ́gẹ́ bí ìlòkulò.

**Àtúnṣe tí a ti fìdí rẹ̀ múlẹ̀ (gẹ́gẹ́ bí àwùjọ ṣe ròyìn, 2026-08-10)**: tún àwọn environment variable mẹ́ta ṣe kí yíyípadà, ìṣiṣẹ́pọ̀ lẹ́ẹ̀kan náà, àti fallback lè gba ìyípadà aláìdúró ti ìpele ọ̀fẹ́ dípò kí wọ́n kùnà nítorí rẹ̀:

```bash
export OMNIROUTE_ROTATE_ON_400=true           # lọ sí model/olùpèsè mìíràn nígbà 400/401 (ó máa fo àwọn model passthrough tó bàjẹ́)
export OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=4   # òrùlé gbígba fún àwọn iṣẹ́ tó wuwo (a kò ṣètò rẹ̀ látìbẹ̀rẹ̀: kò sí òpin iye ìbéèrè, wo àkíyèsí ní ìsàlẹ̀)
export OMNIROUTE_CHAT_ADMISSION_QUEUE_MS=5000 # ìdúró tó ní ààlà tó gùn sí i fún agbára iṣẹ́ tó wuwo dípò 503 tó ṣeé tún gbìyànjú lẹ́sẹ̀kẹsẹ̀
```

Ṣètò àwọn wọ̀nyí nínú àyíká process OmniRoute (daemon náà, fún àpẹẹrẹ nípasẹ̀ LaunchAgent plist tàbí `systemctl edit`), lẹ́yìn náà tún OmniRoute bẹ̀rẹ̀. Àmì yíyípadà náà ni ohun kan ṣoṣo tó ní ipa jù lọ: ó ń yí ìkùnà pátápátá padà sí àtúngbìyànjú tí kò hàn sí olùlò, sí olùpèsè tó ní ìlera nínú àkójọpọ̀ náà.

**Àkíyèsí**: `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` ń fi òpin sí iye àwọn ìbéèrè tó wuwo — tó ní àyíká gígùn — tí ó lè ṣiṣẹ́ lẹ́ẹ̀kan náà; ààlà náà jẹ́ ẹnubodè gbígba, kì í ṣe ohun èlò olùpèsè fún dídín ìwọ̀n ìbéèrè kù. **Ìmúdójúìwọ̀n #503-fanout:** a kò ṣètò var yìí látìbẹ̀rẹ̀ mọ́ (ó ń ṣiṣẹ́ nìkan nígbà tí a bá ṣètò rẹ̀ ní kedere, bíi ti òkè) — dípò bẹ́ẹ̀, ìgbàwọlé iṣẹ́ tó wuwo ni àkópọ̀ byte tí a yọ jáde láìfọwọ́sí (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) ń darí, èyí tí ó ń ṣàtúnṣe ara rẹ̀ ní ìbámu pẹ̀lú òrùlé memory gidi ti host, nítorí náà deployment tuntun yẹ kí ó rí àwọn ìkọ̀sílẹ̀ `503 chat_admission_busy` tó dín kù gan-an láìṣètò var yìí rárá; ṣíṣètò rẹ̀ ní kedere níbí ṣì ń ṣiṣẹ́ gan-an bí a ṣe ṣàkọsílẹ̀ rẹ̀. Àwọn ìyípadà àkópọ̀ byte tí a ṣètò ní kedere ni a fi ààlà sí 8 MiB–2 GiB. `413 body_exceeds_budget` kì í ṣe ohun tó máa kọjá fúnra rẹ̀: mú àkópọ̀ byte náà pọ̀ sí i, dín `OMNIROUTE_CHAT_HARD_MAX_BODY_BYTES` kù, tàbí mú òrùlé memory process náà pọ̀ sí i. Ìtújáde `inflight_bytes_budget` jẹ́ ìjà fún ohun àmúlò fún ìgbà díẹ̀, ó sì ṣì ṣeé tún gbìyànjú. Dídín ìwọ̀n ìbéèrè kù fún olùpèsè kọ̀ọ̀kan (`open-sse/services/rateLimitManager.ts`) ni `RATE_LIMIT_MAX_WAIT_MS`, `RATE_LIMIT_MAX_QUEUE_DEPTH`, àti `RATE_LIMIT_AUTO_ENABLE` ń darí lọ́tọ̀ — wo `.env.example`.

**Bí o ṣe lè ṣàyẹ̀wò pé ó ṣiṣẹ́**: ṣiṣẹ́ aṣojú/cron rẹ lẹ́ẹ̀mejì ní kíákíá, kí o sì fìdí rẹ̀ múlẹ̀ pé àwọn méjèèjì ṣàṣeyọrí. Ṣáájú àtúnṣe náà, ìṣiṣẹ́ kejì sábà máa ń ju `429`/`401` jáde. Lẹ́yìn àtúnṣe náà, a máa tún àwọn ìkùnà (bí èyíkéyìí bá wà) gbìyànjú láìfi hàn sí olùlò, ìpè náà yóò sì parí. O tún lè lo `curl /monitoring/health` kí o sì tọpinpin field `rateLimitedUntil` lórí àwọn ìsopọ̀ olùpèsè àti `circuitBreakers.providerBreakers[].state` fún àwọn olùpèsè tí ọ̀ràn náà kàn — state náà jẹ́ ọ̀kan lára `CLOSED`, `DEGRADED`, `OPEN`, tàbí `HALF_OPEN` (wo `src/shared/utils/circuitBreaker.ts`), olùpèsè tó sì ń kùnà ṣáá yóò yí padà `CLOSED → DEGRADED → OPEN` kí àkókò ìtúntò náà tó jẹ́ kí ìdánwò kan kọjá (`HALF_OPEN`).

**Tí o bá ṣì ń rí 429**: àkọọ́lẹ̀ tó ń ṣiṣẹ́ fún olupèsè yẹn ti lo gbogbo _ìpín lílò_ rẹ̀ tán ní tòótọ́ (kì í ṣe òṣùwọ̀n ìbéèrè nìkan). Ṣàfikún àkọọ́lẹ̀ kejì fún olupèsè kan náà nínú dasibodu OmniRoute → Providers → Accounts, tàbí darapọ̀ mọ́ olupèsè ọ̀fẹ́ mìíràn (fún àpẹẹrẹ, `routeway`, `auggie`). Yíyí àkọọ́lẹ̀ ká máa ń ṣèrànwọ́ fún òṣùwọ̀n ìbéèrè/400/401 tó jẹ́ ti ìgbà díẹ̀ nìkan; bí ìpín lílò bá tán pátápátá, ó nílò ẹ̀rí ìwọlé kejì tàbí olupèsè mìíràn.

**Tí o bá rí 403 lórí àwọn módẹ́ẹ̀lì ìríran (`auto/vision`, `bazaarlink/*`)**: àkọọ́lẹ̀ tí a sopọ̀ kò ní ètò ìsanwó tó ní ìríran nínú, tàbí kọ́kọ́rọ́ API náà kò ní àṣẹ tó pé. Ṣàyẹ̀wò nínú dasibodu olupèsè pé àyè àṣẹ kọ́kọ́rọ́ náà ní ìríran/ọ̀pọ̀-ọ̀nà, tàbí so àkọọ́lẹ̀ ìpele ìsanwó pọ̀, kí o sì fi í sílẹ̀ gẹ́gẹ́ bí ibi-àfojúsùn ìríran.

## Àwọn Ìkìlọ̀ npm install (ERESOLVE / peer / deprecated)

Nígbà tí o bá ṣiṣẹ́ `npm install -g omniroute`, o lè rí ọ̀pọ̀lọpọ̀ ìkìlọ̀ bíi `npm warn ERESOLVE`, àwọn ìfitónilétí nípa peer-dependency, àti àwọn ìfiránṣẹ́ `deprecated`. **Àwọn wọ̀nyí jẹ́ ohun tí a retí, wọn kò sì léwu.** Fífì sori ẹrọ rẹ ṣàṣeyọrí bí o bá rí `added <N> packages` nínú àbájáde náà.

Àwọn ìkìlọ̀ náà wá láti inú àwọn ààlà peer-dependency tí kò ṣe déédé mọ́ nínú àwọn package ẹlòmíràn tí OmniRoute kò ṣàkóso:

1. **`marked-terminal` fẹ́ `marked >=1 <16`, ṣùgbọ́n a rí `marked@18`** — ó ń ṣiṣẹ́ dáadáa ní ti gidi; ààlà peer ti upstream náà ti kàn di àtijọ́.
2. **`deprecated prebuild-install@7.1.3`** — olùrànlọ́wọ́ fún gbígba native-binary tí ó wá nípasẹ̀ dependency mìíràn. A kò
   lò ó láti fi transport binding `wreq-js` tí a ti pin mọ́ ẹ̀yà kan sori ẹrọ, kò sì túmọ̀ sí pé ìṣètò transport
   fún olùpèsè web-cookie kùnà.

**Kò sí ohun tí o nílò láti ṣe** — a kò lè pa àwọn ìkìlọ̀ náà lẹ́nu pátápátá láì ṣe fork àwọn package upstream.

## Àwọn Ìkìlọ̀ Èké Láti Ẹ̀rọ Àjẹsára

<a name="antivirus-false-positives"></a>

### Avast/AVG fi `README.md` sínú àhámọ́ pẹ̀lú `MD:HttpRequest-inf[Susp]`

**Ìkìlọ̀ èké ni èyí. Kò sí ohun tí àkóràn mú, kò sì sí ìgbésẹ̀ kankan tí ó yẹ kí o gbé.**

Avast àti AVG ń lo ìlànà àfojúsùn kan tí ń sàmì sí àwọn fáìlì ọ̀rọ̀-lásán/Markdown tí ó ní ọ̀pọ̀
àsopọ̀ tó dà bí ìbéèrè HTTP. `README.md` ti OmniRoute wà nínú package npm (a
ṣe àkójọ rẹ̀ nínú `package.json` → `files`), nítorí náà ó máa ń dé sí `node_modules/omniroute/README.md`
nígbà ìfikún àgbáyé — ó sì ní nǹkan bíi àpẹẹrẹ `http://localhost:20128/...` mẹ́ẹ̀ẹ́dógún (àwọn
endpoint HTTP/SSE ti MCP, URL `.well-known` ti A2A, àti àwọn àpẹẹrẹ `curl`). Ìpọ̀ àwọn àsopọ̀
yìí ti tó láti mú àfojúsùn náà ṣiṣẹ́.

Bí èyí bá ṣẹ̀ṣẹ̀ bẹ̀rẹ̀ láìpẹ́ yìí: irú fáìlì náà kò yí padà. Tábìlì àwọn endpoint inú README
ti fẹ̀ sí i (a fi MCP HTTP + SSE + A2A kún un), bẹ́ẹ̀ sì ni àwọn àpẹẹrẹ `curl` pọ̀ sí i,
èyí sì mú un kọjá ààlà náà.

Fáìlì náà jẹ́ ìwé àlàyé tí kò lè ṣiṣẹ́, tí kò sì ní àkóónú tí a lè ṣiṣẹ́ rárá. O lè mú un padà
láti inú àhámọ́ láìsí ewu.

**Ohun tí o yẹ kí o ṣe:**

1. **Dá àwọn ìfitónilétí náà dúró** — yọ folda ìfikún náà kúrò nínú ohun tí ẹ̀rọ àjẹsára rẹ
   ń ṣàyẹ̀wò (Avast: Settings → Exceptions), nípa fífi path `node_modules` àgbáyé rẹ àti/tàbí
   folda dátà OmniRoute (`~/.omniroute/`) kún un.
2. **Jábọ̀ ìkìlọ̀ èké náà** — <https://www.avast.com/false-positive-file-form.php>,
   kí o sì so `README.md` tí a fi sínú àhámọ́ mọ́ ọ. Èyí ni àtúnṣe tí ó ń ran gbogbo ènìyàn lọ́wọ́,
   nítorí àfojúsùn olùpèsè náà ló ń fèsì ju bó ṣe yẹ lọ sí fáìlì ọ̀rọ̀ kan.

**Ìdí tí a kò fi “ṣàtúnṣe” èyí ní ẹ̀gbẹ́ wa:** gbogbo àwọn àpẹẹrẹ náà jẹ́ `http://localhost`,
localhost kò sì lè jẹ́ `https` láìsí ìṣòro certificate tí ẹni fúnra rẹ̀ fọwọ́ sí. Yíyí àwọn ìwé
àlàyé náà po láti yẹra fún àfojúsùn olùpèsè kan yóò ṣe gbogbo òǹkàwé níkà láti tẹ́ ẹ̀rọ
àṣàyẹ̀wò tó ní àbùkù lọ́rùn.

### Kaspersky sàmì sí app Desktop gẹ́gẹ́ bí `PDM:Trojan.Win32.Generic`

**Ìkìlọ̀ èké láti inú àfojúsùn ìwà ni èyí. Kò sí ohun tí àkóràn mú.** Àkọ́kọ́-ọ̀rọ̀ `PDM:` ti
Kaspersky túmọ̀ sí pé ìdájọ́ náà wá láti inú Proactive Defense Module (System Watcher) rẹ̀,
èyí tí ń ṣàyẹ̀wò ohun tí installer náà _ń ṣe_ dípò fífi í wé malware tí a ti mọ̀. Nígbà tí
ó bá ṣiṣẹ́, Kaspersky máa ń “yí gbogbo ìfikún náà padà sí bí ó ti wà tẹ́lẹ̀” — nípa pípa àwọn
fáìlì tí ó ti kọ sílẹ̀ rẹ́ — nítorí náà app náà máa ń bàjẹ́ tàbí ó máa ń pòórá.

Àwọn fáìlì tí ó sàmì sí jẹ́ àwọn apá boṣewa láti inú àwọn dependency orísun-ṣíṣí tí a ti kéde,
tí a sì kó pọ̀ mọ́ app desktop náà, fún àpẹẹrẹ:

- `resources/app/.build/next/node_modules/playwright-<hash>/lib/…/agentParser.js` àti
  `workerProcessEntry.js` — [Playwright](https://playwright.dev), library adaṣiṣẹ́ browser
  tí a ń lò fún ìwọlé provider nínú app àti ìfọ̀rọ̀wérọ̀ tí browser ń ṣe àtìlẹ́yìn fún.
- `resources/app/.build/next/node_modules/@wreq-js/binding-win32-<arch>-msvc-<hash>/wreq-js.win32-<arch>-msvc.node`
  — binding abinibi `wreq-js` tí a ti dì mọ́ ẹ̀yà pàtó, tí a ń lò fún HTTP tó ní àmì ìdánimọ̀
  browser lórí àwọn provider kúkì wẹ́ẹ̀bù (`<arch>` jẹ́ `x64` tàbí `arm64`).

**Ìdí tí ó fi ń ṣiṣẹ́:** **a kò tíì fọwọ́sí installer Windows pẹ̀lú code-signing**, nítorí náà
installer NSIS tí kò ní ìfọwọ́sí kò ní òkìkí rárá, àwọn àfojúsùn ìwà sì máa ń ṣiṣẹ́ pẹ̀lú
ìkanra tó ga jù lọ. Nígbà tí èyí bá darapọ̀ mọ́ DLL abinibi tí a kó sínú rẹ̀ àti ọgọ́rọ̀ọ̀rún
fáìlì `.js` tí a kọ sí abẹ́ `%LOCALAPPDATA%\Programs\OmniRoute` (tó fi mọ́ àwọn folda package
tí hash wà ní ìparí orúkọ wọn láti inú build adádúró Next.js), ó ti tó láti mú àfojúsùn náà
ṣiṣẹ́. A ti wéwèé code signing; títí yóò fi dé, àwọn release tuntun lè tún fa èyí.

**Ohun tí o yẹ kí o ṣe:**

1. **Kọ́kọ́ ṣàyẹ̀wò download rẹ** (èyí yóò fi hàn pé a kò yí fáìlì náà padà). Gbogbo release
   máa ń tẹ̀ `latest.yml` jáde, tí field `sha512` rẹ̀ (base64) ń bo installer
   `OmniRoute.Setup.<version>.exe`. Nínú PowerShell, láti inú folda tí installer náà wà:
   ```powershell
   $b = [System.Security.Cryptography.SHA512]::Create().ComputeHash(
     [System.IO.File]::ReadAllBytes("$PWD\OmniRoute.Setup.<version>.exe"))
   [Convert]::ToBase64String($b)
   ```
   Àbájáde náà gbọ́dọ̀ bá `latest.yml` → `sha512` mu. Bí kò bá mu, pa fáìlì náà rẹ́, kí o sì
   tún download rẹ̀ láti [ojú-ewé àwọn release GitHub](https://github.com/diegosouzapw/OmniRoute/releases) nìkan.
2. **Mú padà + yọ kúrò nínú àyẹ̀wò** — mú àwọn ohun tí a yí padà sí bí wọ́n ti wà tẹ́lẹ̀ padà
   láti inú àhámọ́, kí o sì fi `%LOCALAPPDATA%\Programs\OmniRoute` kún àwọn ohun tí a yọ kúrò
   nínú àyẹ̀wò (Kaspersky → Settings → Threats and Exclusions), lẹ́yìn náà tún fi app náà sí.
3. **Jábọ̀ ìkìlọ̀ èké náà** — <https://opentip.kaspersky.com/>. Àwọn ìjábọ̀ FP tí àwọn
   aṣàmúlò fi ránṣẹ́ ń mú kí fífi sí allowlist yára sí i ní tòótọ́.

## Ìbámu Pẹ̀lú Node.js

<a name="nodejs-compatibility"></a>

### Ojú-ìwé ìwọlé kọ́lù tàbí ó ṣàfihàn àṣìṣe "Module self-registration"

**Ohun tó fà á:** O ń lo ẹ̀yà Node.js kan tí kò sí láàárín àwọn ẹ̀yà àkókò-ṣiṣe tó ní ààbò tí OmniRoute fọwọ́ sí. Ohun tó wọ́pọ̀ jù lọ ni lílo ìpele àtúnṣe Node 22 tàbí 24 àgbà kan tó wà ní ìsàlẹ̀ ìpele ààbò tí a ti ṣàtúnṣe, èyí tí OmniRoute béèrè fún.

**Àwọn àmì:**

- Ojú-ìwé ìwọlé ṣàfihàn ojú òfo tàbí àṣìṣe olupin
- Console ṣàfihàn `Error: Module did not self-register` tàbí àwọn àṣìṣe native binding tó jọ ọ́
- Ojú-ìwé ìwọlé ṣàfihàn **àsìá ìkìlọ̀ àwọ̀ ọsàn** pẹ̀lú ẹ̀yà Node rẹ bí àkókò-ṣiṣe náà kò bá sí láàárín ìlànà ààbò tí a ṣe àtìlẹ́yìn fún

**Àtúnṣe:**

1. Fi ẹ̀yà Node.js LTS tí a ṣe àtìlẹ́yìn fún sí ẹrọ (èyí tí a dábàá: Node.js 24.x):
   ```bash
   nvm install 24
   nvm use 24
   ```
2. Ṣàyẹ̀wò ẹ̀yà rẹ: `node --version` gbọ́dọ̀ ṣàfihàn `v24.0.0` tàbí èyí tó tuntun jù ú lọ lórí ìlà 24.x LTS
3. Tún OmniRoute fi sí ẹrọ: `npm install -g omniroute`
4. Tún un bẹ̀rẹ̀: `omniroute`

> **Àwọn ẹ̀yà tó ní ààbò tí a ṣe àtìlẹ́yìn fún:** `>=22.22.2 <23` tàbí `>=24.0.0 <27`. Node.js 24.x LTS (Krypton) àti Node.js 26 ní àtìlẹ́yìn kíkún.

### npm v11+: a kò fi `better-sqlite3` sí ẹrọ (Cannot find module)

<a name="npm-v11-better-sqlite3-not-installed-cannot-find-module"></a>

**Ohun tó fà á:** npm v11 (tó wà pẹ̀lú Node.js 24+) ń dí àwọn script ìfiséẹ̀rọ fún àwọn
dependency àṣàyàn lọ́nà àìyẹsẹ̀. Nítorí pé a ṣe àkójọ `better-sqlite3` nínú `optionalDependencies`
tó sì nílò àkójọpọ̀ abinibi (`node-gyp rebuild`), npm máa ń fò ó kọjá láìsọ ohunkóhun.

**Àwọn àmì:**

- Olupin kọ́lù nígbà tó ń bẹ̀rẹ̀ pẹ̀lú `Cannot find module 'better-sqlite3'`
- `ls node_modules/better-sqlite3` ṣàfihàn "No such file or directory"
- `npm ls better-sqlite3` ṣàfihàn `(empty)`

**Àtúnṣe:**

1. Fọwọ́ sí àwọn script ìfiséẹ̀rọ náà, kí o sì tún fi sí ẹrọ:
   ```bash
   npm approve-scripts better-sqlite3
   npm install
   ```
2. Tàbí fi èyí tí a ti kọ́ tẹ́lẹ̀ sí ẹrọ pẹ̀lú ọwọ́:
   ```bash
   npm pack better-sqlite3@13.0.1
   tar -xzf better-sqlite3-*.tgz -C node_modules
   mv node_modules/package node_modules/better-sqlite3
   rm better-sqlite3-*.tgz
   ```
3. Ṣàyẹ̀wò pé ó ń ṣiṣẹ́: `node -e "require('better-sqlite3')(':memory:').close(); console.log('OK')"`

### macOS: `dlopen` / "slice is not valid mach-o file"

<a name="macos-native-module-rebuild"></a>

**Ohun tó fà á:** Lẹ́yìn `npm install -g omniroute` àgbáyé, ó ṣeé ṣe kí binary abinibi `better-sqlite3` tó wà nínú package náà ti jẹ́ àkójọpọ̀ fún architecture tàbí Node.js ABI tó yàtọ̀ sí èyí tó ń ṣiṣẹ́ lórí ẹ̀rọ náà. Èyí wọ́pọ̀ lórí macOS (Apple Silicon àti Intel méjèèjì) nígbà tí binary tí a ti kọ́ tẹ́lẹ̀ kò bá àyíká rẹ mu.

**Àwọn àmì:**

- Olupin kùnà lẹ́sẹ̀kẹsẹ̀ nígbà tó ń bẹ̀rẹ̀ pẹ̀lú àṣìṣe `dlopen`
- Àṣìṣe náà ní `slice is not valid mach-o file`
- Àpẹẹrẹ kíkún:

```
dlopen(/Users/<user>/.nvm/versions/node/v24.14.1/lib/node_modules/omniroute/app/node_modules/better-sqlite3/build/Release/better_sqlite3.node, 0x0001): tried: '...' (slice is not valid mach-o file)
```

**Àtúnṣe — tún un kọ́ fún àyíká ẹ̀rọ rẹ (kò nílò dídín ẹ̀yà Node.js kù):**

```bash
cd $(npm root -g)/omniroute/app
npm rebuild better-sqlite3
omniroute
```

> **Àkíyèsí:** Èyí tún native binding náà ṣàkójọpọ̀ sí ẹ̀yà Node.js àti CPU architecture ẹ̀rọ rẹ, tó sì ń yanjú àìbámu binary náà. Ààlà àkókò-ṣiṣe tí a ṣe àtìlẹ́yìn fún lọ́nà òṣìṣẹ́ ni **`>=22.22.2 <23` tàbí `>=24.0.0 <27`** (`SUPPORTED_NODE_RANGE` nínú `src/shared/utils/nodeRuntimeSupport.ts`, tó bá field `engines` inú `package.json` mu). Node.js 24.x LTS (Krypton) àti Node.js 26 ní àtìlẹ́yìn kíkún pẹ̀lú `better-sqlite3` v12.x.

## Àwọn Ìṣòro Proxy

<a name="proxy-issues"></a>

### Ìfọwọ́sí olùpèsè ń ṣàfihàn "fetch failed"

**Ìdí:** Ojú-ọ̀nà ìfọwọ́sí kọ́kọ́rọ́ API (`POST /api/providers/validate`) ń kọjá ètò proxy tẹ́lẹ̀, èyí sì ń fa ìkùnà nínú àwọn àyíká tí ó nílò ìdarípasẹ̀ proxy.

**Àtúnṣe (v3.5.5+):** A ti ṣàtúnṣe èyí báyìí. Ìfọwọ́sí olùpèsè ń gba `runWithProxyContext` kọjá, ó sì ń tẹ̀lé àwọn ètò proxy ti ipele olùpèsè àti ti gbogbo ètò láìfọwọ́ṣe.

### Àyẹ̀wò ìlera token kùnà pẹ̀lú "fetch failed"

**Ìdí:** Ìsọdọ̀tun token OAuth lẹ́yìn ìṣisẹ́ kò ń yan ètò proxy fún ìsopọ̀ kọ̀ọ̀kan.

**Àtúnṣe (v3.5.5+):** Olùṣètò àkókò àyẹ̀wò ìlera token ń yan ètò proxy fún ìsopọ̀ kọ̀ọ̀kan báyìí kí ó tó gbìyànjú ìsọdọ̀tun. Ṣe ìmúdójúìwọ̀n sí v3.5.5+.

### Proxy SOCKS5 dáhùn pẹ̀lú "invalid onRequestStart method"

**Ìdí:** Lórí Node.js 22, dispatcher undici@8 kò bá ìmúṣẹ `fetch()` tí a kọ́ sínú Node mu.

**Àtúnṣe (v3.5.5+):** OmniRoute ń lo iṣẹ́ `fetch()` tirẹ̀ ti undici báyìí nígbà tí dispatcher proxy bá ń ṣiṣẹ́, láti rí i dájú pé ìhùwàsí dúró ṣinṣin. Ṣe ìmúdójúìwọ̀n sí v3.5.5+.

### Proxy MITM lábẹ́ WSL: a kò dá àwọn ìṣàfilọ́lẹ̀ desktop dúró lórí ẹ̀rọ Windows abínibí

**Ìdí:** Proxy MITM àti ìwé-ẹ̀rí CA rẹ̀ máa ń fi sórí àyíká tí OmniRoute ti ń ṣiṣẹ́. Lábẹ́ WSL, àyíká yẹn ni Linux àlejò, nígbà tí àwọn ìṣàfilọ́lẹ̀ AI desktop (Kiro, Trae, Copilot, Zed, …) ń ṣiṣẹ́ lórí Windows abínibí. Àwọn ìṣàfilọ́lẹ̀ lórí ẹ̀rọ abínibí kò fọkàn tán ibi ìpamọ́ ìwé-ẹ̀rí ti ẹ̀rọ àlejò, wọn kò sì gba proxy ètò ti ẹ̀rọ àlejò kọjá, nítorí náà dídá ìbánisọ̀rọ̀ desktop dúró kò ṣiṣẹ́ níbẹ̀.

**Ìmọ̀ràn:** Ṣiṣẹ́ OmniRoute lọ́nà abínibí lórí OS kan náà pẹ̀lú àwọn ìṣàfilọ́lẹ̀ desktop tí o fẹ́ dá ìbánisọ̀rọ̀ wọn dúró (Windows fún àwọn ìṣàfilọ́lẹ̀ Windows; bákan náà fún macOS/Linux). Títọ́jú OmniRoute sínú WSL nígbà tí o ń lépa àwọn ìṣàfilọ́lẹ̀ lórí ẹ̀rọ abínibí nílò kí o fọkàn tán ìwé-ẹ̀rí CA tí a ṣẹ̀dá lórí Windows abínibí pẹ̀lú ọwọ́, kí o sì darí àwọn ètò nẹ́tíwọ́ọ̀kì/proxy ti ìṣàfilọ́lẹ̀ kọ̀ọ̀kan sí ojú-ọ̀nà proxy WSL — ètò tí a kò ṣe àtìlẹ́yìn fún, tí ó sì rọrùn láti bàjẹ́.

nípasẹ̀ èyíkéyìí nínú àwọn ọ̀nà àgbéwọlé mẹ́tẹ̀ẹ̀ta.

Fún àlàyé kíkún àti àwọn ìtọ́nisọ́nà ní ìgbésẹ̀-ní-ìgbésẹ̀ fún fífi àkọọ́lẹ̀ Kiro méjì kún un ní ẹ̀gbẹ́ ara wọn,

## Àwọn Ìṣòro Docker

### Docker IPv6 / Ìtúnṣopọ̀ Asopọ̀

<a name="docker-ipv6"></a>

**Àwọn àmì:** `curl http://localhost:20128/v1/models` dá `curl: (56) Recv failure: Connection reset by peer` padà. Dashboard àti àwọn endpoint tí kò nílò ìfàṣẹsí ń ṣiṣẹ́, ṣùgbọ́n àwọn endpoint tí ó nílò ìfàṣẹsí kùnà — ó dà bí ìṣòro ìfàṣẹsí ṣùgbọ́n kì í ṣe bẹ́ẹ̀.

**Okùnfà:** `docker run -p 20128:20128` ṣe àtẹ̀jáde lórí `0.0.0.0` (IPv4) àti `::` (IPv6) méjèèjì, ṣùgbọ́n process inú container ń tẹ́tí sí IPv4 nìkan. Lórí àwọn host tí `localhost` ti kọ́kọ́ resolve sí `::1`, asopọ̀ náà dé port IPv6 tí a tẹ̀jáde láìsí listener lẹ́yìn rẹ̀ → a tún asopọ̀ náà ṣe.

**Àtúnṣe:**

1. **Àyẹ̀wò kíákíá:** Ṣiṣe `curl -4 http://localhost:20128/v1/models`. Tí ó bá ṣiṣẹ́ pẹ̀lú `-4` ṣùgbọ́n tí ó kùnà láìsí i, bind IPv6 rẹ kò bá ara rẹ̀ mu.
2. **Àtúnṣe títí láé:** Ṣe bind sí IPv4 ní pàtó nípa lílo `-p 127.0.0.1:20128:20128` nínú command `docker run` rẹ:
   ```bash
   docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
     -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
   ```
   Èyí fi ipá mú bind IPv4, ó sì tún dènà fífi proxy hàn lórí gbogbo interface host.

### Mú Àwọn Fáìlì Log Ṣiṣẹ́

A ń tọ́jú àwọn artifact request sí abẹ́ `${DATA_DIR}/call_logs/` nígbà tí pipeline log ìpè bá
ṣiṣẹ́ nínú àwọn ààtò.
Nígbà tí capture pipeline bá ṣiṣẹ́, ṣètò `CALL_LOG_PIPELINE_CAPTURE_STREAM_CHUNKS=false` láti yọ
àwọn payload chunk stream kúrò, tàbí ṣàtúnṣe `CALL_LOG_PIPELINE_MAX_SIZE_KB` láti yí ààlà artifact padà ní KB.

### Ṣàyẹ̀wò Ìlera Provider

```bash
# Dashboard ìlera
http://localhost:20128/dashboard/health

# Àyẹ̀wò ìlera API
curl http://localhost:20128/api/monitoring/health
```

### Ìpamọ́ Runtime

- Ipò àkọ́kọ́: `${DATA_DIR}/storage.sqlite` (àwọn provider, combo, alias, key, ààtò)
- Ìlò: Àwọn table SQLite nínú `storage.sqlite` (`usage_history`, `call_logs`, `proxy_logs`) + `${DATA_DIR}/call_logs/` àṣàyàn
- Àwọn log application: `<repo>/logs/...` (nígbà tí `APP_LOG_TO_FILE=true`)
- Àwọn artifact log ìpè: `${DATA_DIR}/call_logs/YYYY-MM-DD/...` nígbà tí pipeline log ìpè bá ṣiṣẹ́

Ìgbésẹ̀ **Clean history** ojú-ìwé Request Logs máa ń pa `call_logs`, `request_detail_logs`
àtijọ́, àti directory artifact agbègbè `${DATA_DIR}/call_logs/` rẹ́.

## Àwọn Ìṣòro Circuit Breaker

### Olùpèsè di sí ipò OPEN

Nígbà tí circuit breaker olùpèsè kan bá wà ní ipò OPEN, a ó dí àwọn ìbéèrè títí àkókò ìsinmi yóò fi parí.

**Àtúnṣe:**

1. Lọ sí **Pátákó Ìṣàkóso → Àwọn Ètò → Ìfaradà**
2. Ṣàyẹ̀wò káàdì circuit breaker fún olùpèsè tí ọ̀ràn náà kàn
3. Tẹ **Ṣàtúntò Gbogbo Rẹ̀** láti pa gbogbo àwọn breaker rẹ́, tàbí dúró kí àkókò ìsinmi parí
4. Jẹ́rìí pé olùpèsè náà wà lárọwọ́tó ní tòótọ́ kí o tó ṣàtúntò rẹ̀

### Olùpèsè ń mú circuit breaker ṣiṣẹ́ léraléra

Tí olùpèsè kan bá ń wọ ipò OPEN léraléra:

1. Ṣàyẹ̀wò **Pátákó Ìṣàkóso → Ìlera → Ìlera Olùpèsè** fún àpẹẹrẹ ìkùnà náà
2. Lọ sí **Àwọn Ètò → Ìfaradà → Àwọn Profaili Olùpèsè**, kí o sì mú ààlà ìkùnà pọ̀ sí i
3. Ṣàyẹ̀wò bóyá olùpèsè náà ti yí àwọn ààlà API padà tàbí ó nílò ìfàṣẹsí tuntun
4. Ṣàgbéyẹ̀wò telemetry ìjáfara — ìjáfara gíga lè fa àwọn ìkùnà tó dá lórí àkókò-píparí

### Àwọn ìṣòro fọ́ọ̀mù tó wọ́pọ̀

- **Àwọn tag ìrònú kò hàn** — Ṣàyẹ̀wò bóyá olùpèsè àfojúsùn ṣe àtìlẹ́yìn fún ìrònú àti ètò ìnáwó ìrònú
- **Àwọn tool call ń sọnù** — Àwọn ìtumọ̀ fọ́ọ̀mù kan lè yọ àwọn field tí a kò ṣètìlẹ́yìn fún; jẹ́rìí èyí ní ipò Pápá Ìdánwò
- **System prompt kò sí** — Claude àti Gemini ń ṣàkóso àwọn system prompt lọ́nà tó yàtọ̀; ṣàyẹ̀wò àbájáde ìtumọ̀
- **SDK ń dá raw string padà dípò object** — A ti yanjú èyí ní v1.x; olùmọ́tótó ìdáhùn ń yọ àwọn field tí kì í ṣe ti ìlànà (`x_groq`, `usage_breakdown`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ) tí ń fa ìkùnà ìfọwọ́sí Pydantic ti OpenAI SDK. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ fi ìṣòro náà léde.
- **GLM/ERNIE kọ ipa `system`** — A ti yanjú èyí ní v1.x; olùṣètò ipa ń da àwọn system message pọ̀ mọ́ àwọn user message fún àwọn módẹ́lì tí kò bá wọn mu. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ fi ìṣòro náà léde.
- **A kò dá ipa `developer` mọ̀** — A ti yanjú èyí ní v1.x; a ń yí i padà sí `system` láìfọwọ́yí fún àwọn olùpèsè tí kì í ṣe OpenAI. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ fi ìṣòro náà léde.
- **`json_schema` kò ṣiṣẹ́ pẹ̀lú Gemini** — A ti yanjú èyí ní v1.x; a ń yí `response_format` padà sí `responseMimeType` + `responseSchema` ti Gemini báyìí. Tí o bá ṣì ń rí èyí lórí v3.x+, jọ̀wọ́ fi ìṣòro náà léde.

## Àwọn Ètò Ìfaradà

### Ìdínwọ̀n ìwọ̀n-ìbéèrè aládàáṣe kò ṣiṣẹ́

- Ìdínwọ̀n ìwọ̀n-ìbéèrè aládàáṣe kan àwọn olùpèsè kọ́kọ́rọ́ API nìkan (kì í ṣe OAuth/ìforúkọsílẹ̀)
- Ṣàyẹ̀wò pé **Settings → Resilience → Provider Profiles** ti mú ìdínwọ̀n ìwọ̀n-ìbéèrè aládàáṣe ṣiṣẹ́
- Ṣàyẹ̀wò bóyá olùpèsè náà ń dá àwọn kóòdù ipò `429` tàbí àwọn àkọlé `Retry-After` padà

### Ṣíṣe àtúnṣe exponential backoff

Àwọn profaili olùpèsè ṣe àtìlẹ́yìn fún àwọn ètò wọ̀nyí:

- **Ìdádúró ìpìlẹ̀** — Àkókò ìdúró àkọ́kọ́ lẹ́yìn ìkùnà àkọ́kọ́ (àìpéye: 1s)
- **Ìdádúró tó pọ̀ jù** — Òpin àkókò ìdúró tó pọ̀ jù (àìpéye: 30s)
- **Olùsọ̀pọ̀** — Iye tí a ó fi mú ìdádúró pọ̀ sí fún ìkùnà kọ̀ọ̀kan tó tẹ̀lé ara wọn (àìpéye: 2x)

### Ìdènà agbo tí ń ya lu

Nígbà tí ọ̀pọ̀ ìbéèrè tó ń lọ lẹ́ẹ̀kan náà bá dé ọ̀dọ̀ olùpèsè tí a ti dín ìwọ̀n-ìbéèrè rẹ̀ kù, OmniRoute máa ń lo mutex + ìdínwọ̀n ìwọ̀n-ìbéèrè aládàáṣe láti tò àwọn ìbéèrè lẹ́sẹẹsẹ àti láti dènà ìkùnà tó ń tàn kálẹ̀. Èyí máa ń ṣẹlẹ̀ láìfọwọ́sí fún àwọn olùpèsè kọ́kọ́rọ́ API.

### Àwọn ìbéèrè ìfọ̀rọ̀wérọ̀ ń kùnà pẹ̀lú 503 / chat_admission_busy

**Àwọn àmì:**

- Endpoint ìparí ìfọ̀rọ̀wérọ̀ ń dá èsì `503` tí a lè tún gbìyànjú padà, tí kóòdù àṣìṣe rẹ̀ jẹ́
  `chat_admission_busy`.
- Èsì náà ní `Retry-After`. Láti #12135, iye náà ni a ń yọ láti inú bí agbègbè náà ṣe kún tó gẹ́gẹ́ bí a ti ṣàkíyèsí — èyí tó tóbi jù láàárín àkókò `OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` tí ìbéèrè náà ti dúró tẹ́lẹ̀ àti àkókò tí a ti di àwọn lease iṣẹ́-wúwo lọ́wọ́lọ́wọ́ mú — tí a sì yí sókè sí àwọn ìṣẹ́jú-àáyá odidi, tí òpin rẹ̀ sì jẹ́ 60. Ní ẹnu-ọ̀nà tí kò dí, ó ń pa àwọn òpin-ìsàlẹ̀ ìtàn mọ́: ìṣẹ́jú-àáyá 2 lórí ipa tó dá lórí byte, ìṣẹ́jú-àáyá 1 lórí ipa tó dá lórí ìgbékalẹ̀ (èyí tí ó tún ní
  `reason: "structure_limit"`).
- Èyí lè ṣẹlẹ̀ nígbà tí ìfọ̀rọ̀wérọ̀ iṣẹ́-wúwo mìíràn tàbí èsì streaming tó ń gba àkókò pípẹ́ ṣì ń lọ lọ́wọ́.

Ara èsì tó dá lórí byte ni:

```json
{
  "error": {
    "message": "Chat admission capacity is temporarily unavailable. Retry shortly.",
    "type": "server_error",
    "code": "chat_admission_busy"
  }
}
```

Èsì tó dá lórí ìgbékalẹ̀ ń lo irú àti kóòdù kan náà, pẹ̀lú ìfiránṣẹ́
`Local chat admission capacity is busy for this structurally heavy request; upstream provider routing was not attempted. Retry shortly.`
àti `reason: "structure_limit"`.
Ní àwọn òpin àìpéye, ìbéèrè kan jẹ́ iṣẹ́-wúwo nípa ìgbékalẹ̀ nígbà tí ó bá ní ó kéré tán àwọn ìfiránṣẹ́ `200`,
ó kéré tán àwọn irinṣẹ́ `64`, tàbí ó kéré tán àwọn token àfojúsùn `32,000`, tàbí nígbà tí ìṣírò ìgbékalẹ̀ ọlọ́pìn
bá parí gbogbo òpin rẹ̀ ti node `10,000` tí a bẹ̀wò tàbí ìjìnlẹ̀ `12`.

**Okùnfà:** Èyí jẹ́ dídín ẹrù kù tí a mọ̀ọ́mọ̀ ṣe nínú OmniRoute, kì í ṣe ìkùnà olùpèsè upstream.
Process kọ̀ọ̀kan ń lo olùṣọ́ tó jẹ́ ti process náà nìkan láti fi agbára iṣẹ́-wúwo tó ní òpin pamọ́ ṣáájú dídadúró
àti ṣíṣe parsing ara ìbéèrè ńlá kan. Lease iṣẹ́-wúwo kan máa wà ní dídìmú fún gbogbo àkókò tí èsì SSE bá wà.

**#503-fanout:** ṣáájú àtúnṣe yìí, olùṣọ́ náà máa ń fi òpin sí concurrency ní COUNT ìbéèrè tí kò yí padà
(`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`, àìpéye `1`) láìka memory host sí, nítorí náà fan-out coding-agent
(ọ̀pọ̀ subagents/CLIs, àwọn ara tí ó sábà máa ń tóbi ju 256 KB) ṣubú sí concurrency tó fẹ́rẹ̀ẹ́ jẹ́
~1, ó sì ń dá 503 padà lábẹ́ ẹrù tó jẹ́ ti àjọṣe pátápátá. Ní báyìí, olùṣọ́ náà ń ṣàtúnṣe ara rẹ̀: budget BYTE ingest tí a ń yọ jáde láìfọwọ́sí (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`) tí a ṣe ìwọ̀n rẹ̀ láti inú
òpin memory gidi ti process náà ni ó ń darí rẹ̀, ó sì tún ń wo àmì titẹ̀-resource tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́ — nítorí náà,
ìgbà tí host bá wà lábẹ́ titẹ̀ memory gidi nìkan ni ó máa ń dín ẹrù kù, kì í ṣe nítorí pé ìbéèrè iṣẹ́-wúwo tó ju ẹyọ kan lọ
dé lẹ́ẹ̀kan náà. A ṣì ń tẹ̀lé òpin COUNT àtijọ́ (`OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT`), ṣùgbọ́n kìkì bí o bá ṣètò rẹ̀ ní tààrà.

Nígbà tí agbára bá dí, ìbéèrè iṣẹ́-wúwo kan yóò kọ́kọ́ dúró tó
`OMNIROUTE_CHAT_ADMISSION_QUEUE_MS` (àìpéye `2000`, `0` máa pa ìdúró náà) kí slot kan lè ṣí sílẹ̀
kí ó tó dá `503` tí a lè tún gbìyànjú padà. Ìdúró ọlọ́pìn náà wà kí àwọn client irú-agent
(OpenCode, Claude Code, Cursor) tí ń ṣe fan-out àwọn ìbéèrè-kékeré iṣẹ́-wúwo lẹ́ẹ̀kan náà lè tò ìgbì ìbéèrè náà lẹ́sẹẹsẹ
dípò kí wọ́n fi ìkọ̀sílẹ̀ lẹ́sẹ̀kẹsẹ̀ ná gbogbo budget àtúngbìyànjú wọn tán, kí wọ́n sì dáwọ́ dúró láàárín iṣẹ́.
Bí àwọn lease iṣẹ́-wúwo lọ́wọ́lọ́wọ́ ṣe kún tó, budget byte tí a yanjú, àti bí titẹ̀ lọ́wọ́lọ́wọ́ ṣe le tó
ni a fi hàn ní `GET /api/monitoring/health` → `chatAdmission` (`inflightBytes`, `maxInflightBytes`,
`budgetSource`, `pressureSeverity`, `countCapEnabled`) — ṣàyẹ̀wò àwọn wọ̀nyí kí o tó fọwọ́ kan env var èyíkéyìí.
Settings → Resilience → Request Queue → Concurrent Requests kò ṣàkóso èyí; ètò yẹn
ń ṣàkóso ọ̀nà request-queue olùpèsè ọ̀tọ̀ kan.

**Àtúnṣe:**

1. Kọ́kọ́ tún gbìyànjú. Àwọn client gbọ́dọ̀ tẹ̀lé `Retry-After`, kí wọ́n sì lo backoff dípò títún
   fi ìbéèrè náà ránṣẹ́ lẹ́sẹ̀kẹsẹ̀.
2. Ṣàyẹ̀wò `/api/monitoring/health` → `chatAdmission` kí o tó ṣàtúnṣe ohunkóhun. `countCapEnabled:
false` àti `maxInflightBytes` tó tóbi túmọ̀ sí pé budget tí a yọ jáde láìfọwọ́sí ti ń ṣe
   iṣẹ́ rẹ̀ dáadáa; `pressureSeverity` ti `high`/`critical` túmọ̀ sí pé memory host náà kéré ní tòótọ́ —
   env var admission kò lè ṣàtúnṣe ìyẹn; ó nílò RAM púpọ̀ sí i tàbí ẹrù iṣẹ́ tó kéré sí i.
3. Kìkì bí `/api/monitoring/health` bá fi hàn pé budget tí a yọ jáde láìfọwọ́sí kéré jù fún
   host rẹ ní tòótọ́ (èyí ṣọ̀wọ́n — ó ti ń ṣe scaling láti container sí bare-metal), ṣàkóso rẹ̀ ní tààrà pẹ̀lú
   `OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES` dípò pípadà sí òpin COUNT ìbéèrè àtijọ́.

Wo [ìtọ́kasí environment-variable](../reference/ENVIRONMENT.md#4-security--authentication)
fún àwọn ètò admission tó jẹ́ ojúlówó.

## Àṣàyàn àkójọpọ̀ àwọn ìṣòro ìkùnà RAG / LLM (ìṣòro 16)

Àwọn olùṣàmúlò OmniRoute kan máa ń fi ẹnu-ọ̀nà náà sí iwájú àwọn àkójọpọ̀ RAG tàbí aṣojú. Nínú irú ìṣètò bẹ́ẹ̀, ó wọ́pọ̀ láti rí àpẹẹrẹ àjèjì kan: OmniRoute dà bí ẹni pé ó ń ṣiṣẹ́ dáadáa (àwọn olùpèsè ń ṣiṣẹ́, àwọn prófáìlì ìdarí tọ̀nà, kò sí ìkìlọ̀ ààlà ìbéèrè) ṣùgbọ́n ìdáhùn ìkẹyìn ṣì jẹ́ àìtọ́.

Ní ìṣe, àwọn ìṣẹ̀lẹ̀ wọ̀nyí sábà máa ń wá láti inú ọ̀nà ṣiṣàn RAG tó wà lẹ́yìn rẹ̀, kì í ṣe láti inú ẹnu-ọ̀nà náà fúnra rẹ̀.

Tí o bá fẹ́ àwọn ọ̀rọ̀ àpapọ̀ láti ṣàpèjúwe àwọn ìkùnà wọ̀nyẹn, o lè lo WFGY ProblemMap, ohun àmúlò ọ̀rọ̀ ìta lábẹ́ ìwé-àṣẹ MIT tí ó ṣàlàyé àpẹẹrẹ ìkùnà RAG / LLM mẹ́rìndínlógún tí ń ṣẹlẹ̀ léraléra. Ní ìpele gíga, ó kó àwọn wọ̀nyí sínú:

- yíyapa ìmúpadàwá kúrò ní ibi-afẹ́ àti àwọn ààlà àyíká-ọ̀rọ̀ tó bàjẹ́
- àwọn atọ́ka àti ibi ìpamọ́ vector tí ó ṣófo tàbí tí kò bá àkókò mu
- àìbáramu láàárín embedding àti ìtumọ̀
- àwọn ìṣòro pípèsè prompt àti fèrèsé àyíká-ọ̀rọ̀
- ìwópalẹ̀ ọgbọ́n ìrònú àti àwọn ìdáhùn tó ní ìgbẹ́kẹ̀lé àṣejù
- ìkùnà pq gígùn àti ìṣọ̀kan àwọn aṣojú
- yíyapa ìrántí àti ipa láàárín ọ̀pọ̀ aṣojú
- àwọn ìṣòro ìtẹ̀jáde àti ìtòlẹ́sẹẹsẹ ìbẹ̀rẹ̀

Èrò náà rọrùn:

1. Nígbà tí o bá ń ṣèwádìí ìdáhùn búburú kan, ṣàkọsílẹ̀:
   - iṣẹ́ àti ìbéèrè olùṣàmúlò
   - àkópọ̀ ọ̀nà tàbí olùpèsè nínú OmniRoute
   - àyíká-ọ̀rọ̀ RAG èyíkéyìí tí a lò lẹ́yìn rẹ̀ (àwọn ìwé tí a mú padà wá, àwọn ìpè irinṣẹ́, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ)
2. So ìṣẹ̀lẹ̀ náà pọ̀ mọ́ nọ́mbà WFGY ProblemMap kan tàbí méjì (`No.1` … `No.16`).
3. Fi nọ́mbà náà pamọ́ sínú pátákó ìṣàkóso, ìwé ìtọ́sọ́nà iṣẹ́, tàbí ohun ìtọpinpin ìṣẹ̀lẹ̀ tirẹ lẹ́gbẹ̀ẹ́ àwọn àkọsílẹ̀ OmniRoute.
4. Lo ojú-ìwé WFGY tó bá a mu láti pinnu bóyá o nílò láti yí àkójọpọ̀ RAG, ohun ìmúpadàwá, tàbí ọgbọ́n ìdarí rẹ padà.

Ọ̀rọ̀ kíkún àti àwọn ìlànà tó ṣe kedere wà níbí (ìwé-àṣẹ MIT, ọ̀rọ̀ nìkan):

[README WFGY ProblemMap](https://github.com/onestardao/WFGY/blob/main/ProblemMap/README.md)

O lè kọjá abala yìí tí o kò bá ń ṣiṣẹ́ àwọn ọ̀nà ṣiṣàn RAG tàbí aṣojú lẹ́yìn OmniRoute.

## Àwọn Ìṣòro Tí A Mọ̀ Nípa v3.8.0

Àwọn ìṣòro tó jẹ́ ti ìtújáde v3.8.0 ní pàtó àti àwọn ọ̀nà àkókò láti yanjú wọn lọ́wọ́lọ́wọ́. Tí àtúnṣe kan bá dé nínú patch tó tẹ̀lé, a ó ṣe àfikún sí àkọsílẹ̀ náà tàbí yọ ọ́ kúrò.

### Ìkùnà ìfàṣẹsí Devin CLI

**Àwọn àmì:**

- "A kò rí Devin CLI" tàbí "ìfàṣẹsí kùnà" nígbà tí a bá ń pe àwọn irinṣẹ́ tí Devin ń ṣe àtìlẹ́yìn fún
- Àyẹ̀wò àsìkò ìṣiṣẹ́ CLI ń fi `installed=false` hàn

**Àwọn ohun tó ń fà á:**

- `CLI_DEVIN_BIN` tọ́ka sí ipa-ọ̀nà tí kò sí
- A kò fi Devin CLI sori host náà

**Àtúnṣe:**

1. Fi Devin CLI sori ẹrọ fún platform rẹ
2. Ṣètò `CLI_DEVIN_BIN=/usr/local/bin/devin` (tàbí ipa-ọ̀nà gidi) nínú `.env`
3. Tun OmniRoute bẹ̀rẹ̀, kí o sì tún dán an wò láti **Pátákó Ìṣàkóso → Àwọn Irinṣẹ́ CLI**

### Cooldown model di (ìtúnṣètò afọwọ́ṣe)

**Àwọn àmì:**

- Model kan ṣì wà nínú àkójọ cooldown lẹ́yìn tí àkókò ìparí rẹ ti kọjá
- Àwọn ìbéèrè ṣì ń fo model náà kọjá nínú ìdarí àkópọ̀ bí ó tilẹ̀ jẹ́ pé timestamp náà ti kọjá

**Ìtúnṣètò afọwọ́ṣe:**

- **Pátákó Ìṣàkóso:** **Àwọn Ètò → Àwọn Cooldown Model** → tẹ **Mú ṣiṣẹ́ lẹ́ẹ̀kan sí i** lórí káàdì tí ìṣòro náà kàn
- **API:** `DELETE /api/resilience/model-cooldowns` pẹ̀lú àwọn akọlé ìfàṣẹsí ìṣàkóso

### Ìsopọ̀ olùpèsè Command Code kùnà pẹ̀lú 403

**Àwọn àmì:**

- 403 nígbà tí a bá ń dán ìsopọ̀ olùpèsè Command Code wò
- Káàdì olùpèsè ń fi "kò ní àṣẹ" hàn lẹ́yìn fífikún tuntun

**Ohun tó ń fà á:** Ìṣàn OAuth kò parí (a kò gba callback tàbí a kò fi token pamọ́).

**Àtúnṣe:**

- Ṣiṣe `omniroute providers` láti inú CLI láti tún ìṣàn OAuth bẹ̀rẹ̀, tàbí
- Tún OAuth ṣiṣẹ́ láti **Pátákó Ìṣàkóso → Àwọn Olùpèsè → Command Code → Tún Sopọ̀**

### ModelScope ń dá cooldown 429 tó le padà

**Àwọn àmì:**

- Cooldown kúkúrú gan-an tàbí lẹ́sẹ̀kẹsẹ̀ lórí ModelScope lẹ́yìn ìṣúpọ̀ ìbéèrè kékeré
- Ìdarí àkópọ̀ ń fo ModelScope kọjá ṣáájú àkókò tí a retí

**Ohun tó ń fà á:** ModelScope ń fi àwọn akọlé `Retry-After` tó jẹ́ ti olùpèsè pàtó ránṣẹ́. v3.8.0 ní ìmúlò pàtó fún àwọn akọlé wọ̀nyẹn, nítorí náà àwọn ẹ̀yà àtijọ́ máa ń túmọ̀ wọn ní àìtọ́ gẹ́gẹ́ bí àwọn ìtọ́kasí ààlà ìbéèrè gbogbogbò.

**Àtúnṣe:**

- Rí i dájú pé o wà lórí v3.8.0 tàbí tuntun jù bẹ́ẹ̀ lọ
- Jẹ́rìí sí i pé toggle `useUpstream429BreakerHints` ti ṣiṣẹ́ lábẹ́ **Àwọn Ètò → Ìfaradà Ìkùnà**

### `OMNIROUTE_WS_BRIDGE_SECRET` kò sí ní production

**Àwọn àmì:**

- 401 lórí gbogbo ìbéèrè afárá WebSocket Codex/Responses nígbà tí ó ń ṣiṣẹ́ lórí host production jíjìn
- Handshake afárá WebSocket máa ń pa lẹ́sẹ̀kẹsẹ̀ lẹ́yìn ìsopọ̀

**Ohun tó ń fà á:** Env var `OMNIROUTE_WS_BRIDGE_SECRET` kò sí nínú environment production.

**Àtúnṣe:**

1. Ṣẹ̀dá secret aláìlétò kan: `openssl rand -hex 32`
2. Ṣètò `OMNIROUTE_WS_BRIDGE_SECRET=<random-secret>` nínú env server production (àti nínú client èyíkéyìí tó ń bá afárá náà sọ̀rọ̀)
3. Tun OmniRoute bẹ̀rẹ̀

### Responses API: background mode dín kù sí synchronous

**Àwọn àmì:**

- Ìkìlọ̀ tí a kọ sínú àkọsílẹ̀: `background mode degraded to synchronous`
- Ìbéèrè `background: true` kan dá ìdáhùn synchronous deede padà dípò ohun ìtọ́ka iṣẹ́ background

**Ohun tó ń fà á:** v3.8.0 mọ̀ọ́mọ̀ ń dín `background: true` lórí Responses API kù sí ìṣiṣẹ́ synchronous nígbà tó tún ń fi ìkìlọ̀ ránṣẹ́. Ìṣiṣẹ́ background async kíkún jẹ́ ohun tí a ó pèsè lọ́jọ́ iwájú.

**Àtúnṣe:**

- Ṣàtúnṣe client náà kí ó lè ṣe ìpè láìsí `background`, tàbí
- Dúró de ìtújáde tó tẹ̀lé tí yóò ní background mode async kíkún (tọpinpin changelog náà)
